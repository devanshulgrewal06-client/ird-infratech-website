# IRD Infratech — Static HTML Website

This version is a **static website**. It does not require Node.js, Express, SQLite, a database, or an admin backend.

## Open it
Double-click `index.html` to open the website in Chrome/Safari.

All pages are linked with relative HTML paths, so the site can also be uploaded to any normal static web host.

## Pages
- `index.html` — Home, services, contact
- `about.html` — Company story, approach and leadership
- `pillar-of-strength.html` — Plant, machinery and workforce
- `clients.html` — Client information
- `projects.html` — Project information
- `project.html` — Individual project detail template
- `managing-director.html` — Managing Director profile
- `logo.png` — Company logo
- `css/style.css` — Shared styling
- `js/script.js` — Mobile navigation and visual effects

## Important
No Managing Director photograph was present in the supplied `version1.zip`, so the Managing Director page uses the company logo as a temporary visual placeholder and clearly states that a real photograph can be inserted later.

No project names/photos were present in the supplied website data, so the project pages do not invent project information.

No admin/login/backend is included in this version. Content is written directly into the HTML pages.
